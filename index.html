One-time setup
You only do this once.

After you connect, your token is saved in this browser. Next time you open Release Balls, you go straight to the race.

  1. Create a read-only token

    Release Balls reads releases and pull requests through the GitHub API, which needs a personal access token.

    Generate token on GitHub
    Leave Repository access on Public repositories. No extra permissions needed. For private repos, pick them and set Contents and Pull requests to Read-only. Prefer a classic token? Create one with no scopes.

  2. Paste it here

    • Saved in a cookie on this device for 90 days. No sign-in needed on your next visit.
    • Only ever sent to api.github.com, never to us or anyone else.
    • Remove it anytime with Remove token in the top bar.
